## ✨ Возможности

- 🔍 **Анализ файлов** — просмотр статистики перед сортировкой
- 📊 **Визуальная статистика** — цветные диаграммы и индикаторы
- 🎨 **Современный дизайн** — красивый и удобный интерфейс
- 🛡️ **Защита данных** — автоматическая защита программных папок
- ↩️ **Отмена действий** — возможность отменить последнюю сортировку
- 🚀 **Портативность** — работает без установки Python

## 📥 Установка

### Вариант 1: Портативная версия (рекомендуется)

1. Скачайте **[FileFlow_v0.4.zip](https://github.com/Expense22/FileFlow/releases/download/v0.4/FileFlow_v0.4.zip)**
2. Распакуйте архив в любую папку
3. Запустите `FileFlow.exe`

### Вариант 2: Из исходного кода

```bash
# Клонируйте репозиторий
git clone https://github.com/Expense22/FileFlow.git
cd FileFlow

# Установите зависимости
pip install -r requirements.txt

# Запустите программу
python main.py
